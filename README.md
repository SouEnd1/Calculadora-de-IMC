# 🧮 Calculadora de IMC

Aplicação web desenvolvida com **HTML, CSS e JavaScript** para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário, exibindo o resultado e sua classificação.

O projeto foi desenvolvido como parte dos estudos de desenvolvimento web, com foco na prática de lógica de programação, manipulação do DOM e integração entre HTML, CSS e JavaScript.

## 🚀 Funcionalidades

- Cálculo automático do Índice de Massa Corporal (IMC).
- Exibição do resultado com duas casas decimais.
- Classificação do resultado de acordo com faixas de IMC.
- Interface simples e intuitiva.
- Atualização dinâmica das informações na página.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação da página.
- **CSS3:** estilização e organização visual da interface.
- **JavaScript:** lógica de cálculo, classificação e manipulação do DOM.

## 📂 Estrutura do projeto

```text
Atividade-Js-com-Front/
├── index.html       # Estrutura da aplicação
├── estilo.css       # Estilos da interface
└── calculadora.js   # Lógica de cálculo do IMC
```

## ▶️ Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/SouEnd1/Atividade-Js-com-Front.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Atividade-Js-com-Front
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a aplicação.
